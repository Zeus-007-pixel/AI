6.1Why NumPy?

On Day 2 you needed a for loop to compute density at 5 altitudes. NumPy (Numerical Python) adds the array: a list of numbers that you can do math on all at once. This is called vectorized math. It's shorter, clearer, and much faster for large data. OpenMDAO and Dymos are built on NumPy arrays. New file d06_first.py:

{{code:d06_first.py}} {{out:d06_first.py}}
import numpy as np
Everyone nicknames NumPy np.
np.linspace(0, 80000, 9)
9 evenly spaced numbers from 0 to 80000, both ends included.
1.225 * np.exp(-h / 8500)
h is an array, so -h / 8500 divides every element, np.exp takes eˣ of every element, and the result is an array of 9 densities. No loop.

Reading 1.16484119e-01

NumPy prints in scientific notation when numbers have very different sizes. e-01 means × 10⁻¹, so 1.16484119e-01 = 0.116 and 1.00151766e-04 = 0.0001.

6.3Lists vs arrays: the big difference

{{code:d06_list_vs_array.py}} {{out:d06_list_vs_array.py}}

A list times 2 is the list repeated. An array times 2 multiplies every element. Two arrays of the same length combine element by element: first with first, second with second, and so on. For numbers, use arrays.

6.4Picking out elements

{{code:d06_index.py}} {{out:d06_index.py}}
rho[0], rho[-1], rho[2:5]
Indexing and slicing work exactly like lists (Day 2).
rho[::2]
A slice with a step: every second element.
high = h > 40000
A comparison on an array gives an array of True/False, one per element. This is called a mask.
h[high]
Using a mask as an index keeps only the elements where the mask is True.
rho.max(), rho.min(), rho.mean()
Summaries of the whole array.
np.argmax(rho)
The index (position) of the largest value, not the value itself. Very useful: if i = np.argmax(LD), then alpha[i] is the angle where L/D is largest.

6.5Tables: 2D arrays

Aerodynamic data often comes as a table, for example CL for several Mach numbers (rows) and angles of attack (columns). New file d06_2d.py:

{{code:d06_2d.py}} {{out:d06_2d.py}}
  • A 2D array is made from a list of lists, one inner list per row.
  • .shape is (rows, columns).
  • CL_table[1, 2] means row 1, column 2 (both counted from 0).
  • : alone means "all": [0, :] is the whole of row 0, and [:, 1] is the whole of column 1.

6.6Interpolating in a table

Your table has CL at 0°, 5° and 10°, but you need 7.5°. Interpolation draws a straight line between the neighbouring points. New file d06_interp.py:

{{code:d06_interp.py}} {{out:d06_interp.py}}

np.interp(x_wanted, x_table, y_table) works for one value or for a whole array. Two rules: x_table must be in increasing order, and outside the table it does not extrapolate. It just returns the first or last value. Remember that when your HGV flies outside its aero data.

6.7Saving and loading arrays

NumPy reads and writes CSV files in one line each, replacing all of Day 4's manual work. New file d06_save_load.py:

{{code:d06_save_load.py}} {{out:d06_save_load.py}}
np.column_stack([h, rho])
Glues two 1D arrays side by side into a 2-column table.
np.savetxt(…, delimiter=",", header="h_m,rho", comments="")
Writes the table with commas between columns and a header line. comments="" stops NumPy putting a # in front of the header.
np.loadtxt(…, delimiter=",", skiprows=1)
Reads it back as a 2D array, skipping the header row.
data[:, 1]
All rows, column 1: the density column.

6.8Use np. functions on arrays, not math.

{{code:d06_math_vs_np.py}} {{out:d06_math_vs_np.py|label=Output (an error, on purpose)}}

The math module only understands single numbers. On arrays, use np.sin, np.cos, np.tan, np.exp, np.log, np.sqrt, np.radians, np.degrees and np.pi. They also work on single numbers, so from now on just use the np. versions.
