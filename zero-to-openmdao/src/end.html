import numpy as np import openmdao.api as om class MyComp(om.ExplicitComponent): def initialize(self): # options self.options.declare('num_nodes', types=int, default=1) self.options.declare('S', default=10.0) def setup(self): # variables + derivatives nn = self.options['num_nodes'] self.add_input('q', val=np.ones(nn), units='Pa') self.add_input('CL', val=np.ones(nn)) self.add_output('L', val=np.zeros(nn), units='N') self.declare_coloring(wrt='*', method='cs') # easy, accurate derivatives # or analytic: # ar = np.arange(nn) # self.declare_partials('L', ['q', 'CL'], rows=ar, cols=ar) def compute(self, inputs, outputs): # the physics outputs['L'] = inputs['q'] * self.options['S'] * inputs['CL'] # def compute_partials(self, inputs, partials): # only for analytic # partials['L', 'q'] = self.options['S'] * inputs['CL'] # partials['L', 'CL'] = inputs['q'] * self.options['S']

Glossary

Argument
A value you pass into a function when you call it: density(5000).
Array
A NumPy list of numbers that supports element-by-element math.
Attribute
A value stored on an object: self.mass.
Boundary constraint
Dymos: a condition at the start or end of a phase.
Class / object
A blueprint, and a thing built from it.
Collocation
Dymos's method: guess states at all nodes and force the defects to zero.
Component
OpenMDAO: one calculation block with inputs and outputs.
Connection
OpenMDAO: an output feeding an input, by promotion or connect.
Constraint
A condition on a result the optimizer must satisfy.
Control
Dymos: a variable whose whole history the optimizer chooses, such as α(t).
Defect
Dymos: the mismatch between a drawn trajectory's slope and the ODE's rate at a node.
Design variable
What the optimizer is allowed to change.
Dictionary
Values stored under keys: d["mass"].
Driver
OpenMDAO: what runs the model repeatedly, usually an optimizer.
Explicit / implicit
Output from a formula, versus output defined by a residual that must be zero.
f-string
Text with values inserted: f"{x:.2f}".
Function
A named, reusable recipe: def name(params): … return.
Group
OpenMDAO: a container of components and groups.
Index
A position in a list or array, counted from 0.
Inheritance
A class built on a parent class: class Glider(Vehicle).
Jacobian
The table of all partial derivatives of outputs with respect to inputs.
Method
A function that belongs to a class: glider.weight().
Module / library
A file of code you can import / a collection of modules (NumPy, OpenMDAO).
Node
Dymos: one of the points in time where states and controls are defined.
Objective
The single number the optimizer minimizes (or maximizes).
ODE
Equations giving the rates of change of the states.
Option
OpenMDAO: a fixed setting chosen when the model is built.
Parameter
Python: a function's input name. Dymos: a fixed (or optimized) value sent to the ODE.
Partial derivative
The slope of one output with respect to one input, others held fixed.
Path constraint
Dymos: a condition enforced at every node.
Phase
Dymos: one stretch of a trajectory with one ODE.
Promote
OpenMDAO: lift variables to a group's level by name. Same names connect.
Residual
A quantity that must become zero when an implicit output is right.
Scaling (ref)
Telling the optimizer a typical size, so it works with numbers around 1.
self
Inside a method: the object the method is working on.
Solver
OpenMDAO: an algorithm (such as Newton) that drives residuals to zero.
State
The numbers describing the vehicle at one instant (position, speed, angles).
Timeseries
Dymos: every variable's value at every node, after solving.
Traceback
Python's error report. Read it from the bottom up.
Transcription
Dymos: how time is split into segments and nodes (Radau, GaussLobatto).
Vectorized
Doing the same math on many values at once, with no loop.
