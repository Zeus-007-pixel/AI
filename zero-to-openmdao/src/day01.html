1.1What programming is

A program is a list of instructions that a computer carries out one after another, exactly as written. It doesn't guess what you meant. If you write something slightly wrong, it either stops with an error message or quietly does the wrong thing.

Python is a language for writing those instructions. It reads almost like English, it's free, and engineers use it everywhere because of its libraries: ready-made code that other people wrote and shared. You'll use these libraries:

  • NumPy: fast math on lists of numbers
  • Matplotlib: plots
  • SciPy: simulations and simple optimizers
  • OpenMDAO: building and optimizing engineering models (NASA made it)
  • Dymos: trajectory optimization, built on OpenMDAO

A Python program is a plain text file whose name ends in .py. You write it in an editor (we use VS Code) and run it with Python.

Mac users

1.4Comments

Anything after a # on a line is a comment. Python ignores it completely. Comments are notes for humans, including future you. Use them to say what a number means or why a line exists.

# This whole line is a comment g = 9.81 # gravity in m/s^2 (the part after # is a comment too)

1.5Variables: named boxes for values

A variable is a name that holds a value. Make a new file d01_variables.py:

{{code:d01_variables.py}} {{out:d01_variables.py}}
mass = 1000.0
Creates a variable called mass and stores 1000.0 in it. The = sign means "store the value on the right under the name on the left". It is not "equals" from maths, and it always works right-to-left.
g = 9.81
Same idea: a variable g holding 9.81.
weight = mass * g
Python first works out the right side: it looks up mass (1000.0) and g (9.81) and multiplies them (* means multiply). Then it stores the answer, 9810.0, in a new variable weight.
print(weight)
Prints the value stored in weight. There are no quotes, because we want the variable's value, not the word "weight".
print("The weight is", weight, "newtons")
You can give print several things separated by commas. It prints them in order with a space between each.

Rules for names: use letters, digits and underscores (_). A name can't start with a digit and can't contain spaces. Capitals matter: Mass and mass are two different names. Pick names that say what the value is: wing_area is better than x.

Variables can change. Storing a new value replaces the old one:

count = 1 count = count + 1 # right side first: 1 + 1 = 2, then store 2 back in count print(count) # 2

Read count = count + 1 as "the new count is the old count plus one". You'll use this pattern constantly.

1.7The math module: square roots, sines and π

Basic Python has no square root or sine. These live in a module, an extra toolbox of functions, called math. You load it with import. New file d01_math_module.py:

{{code:d01_math_module.py}} {{out:d01_math_module.py}}
import math
Loads the math toolbox. Put imports at the top of the file.
h = 100e3
100 × 10³ = 100 000 metres. Scientific notation keeps big numbers readable.
r = R_earth + h
Distance from Earth's centre.
v_orbit = math.sqrt(mu / r)
math.sqrt means "the sqrt function from the math toolbox". The dot means "inside". Python works out mu / r first, then takes its square root: the circular orbit speed v = √(μ/r).
print(math.pi)
math.pi is a value stored in the toolbox: π.

Other useful ones: math.sin(x), math.cos(x) and math.tan(x). Angles are in radians, so convert with math.radians(45) and math.degrees(0.785). Also math.exp(x) for eˣ and math.log(x) for the natural log.

1.8Printing numbers neatly with f-strings

7848.432857300987 has far too many decimals. An f-string lets you put values inside text and choose how they look. New file d01_fstrings.py:

{{code:d01_fstrings.py}} {{out:d01_fstrings.py}}
f"Orbit speed: {v_orbit} m/s"
The f just before the opening quote turns on f-string mode. Anything inside curly braces { } is worked out and its value is placed in the text.
{v_orbit:.1f}
The part after the colon is a format. .1f means "a decimal number with 1 digit after the point". .2f means 2 digits, and .0f means none.
{v_orbit / 1000:.2f}
You can put a calculation inside the braces. Here it converts to km/s first, then formats.

Other formats you'll see: {x:.3e} gives scientific notation like 7.848e+03, and {n:5d} gives a whole number padded to 5 characters wide, which lines up columns.

type(x) tells you the type of x. len(x) tells you how many characters are in a string. + joins two strings together, and * repeats one.

Common error: mixing text and numbers

"Mass: " + 1000 fails with TypeError: can only concatenate str (not "int") to str, because Python won't glue text and a number together. Turn the number into text with str(1000), or simply use an f-string: f"Mass: {1000}".

1.10Errors are normal: how to read them

Every programmer sees errors all day. They're not failures; they're Python telling you exactly what it couldn't do. Make d01_error.py with a deliberate typo (mas instead of mass):

{{code:d01_error.py}} {{out:d01_error.py|label=Output (an error)}}

An error report is called a traceback. Read it from the bottom up:

  1. Last line: what went wrong. NameError: name 'mas' is not defined means Python doesn't know any variable called mas. It even suggests mass.
  2. The lines above: where. The file name, line 3, the line itself, and ^^^ marks pointing at the problem. Your real file path appears where this shows just the file name.
ErrorWhat it usually means
SyntaxErrorThe grammar is broken: a missing bracket, quote or colon. Python found it before running anything.
NameErrorYou used a name that doesn't exist. Usually a typo, or you used a variable before creating it.
TypeErrorWrong kind of value for the operation, like adding text to a number.
IndentationErrorThe spaces at the start of a line are wrong (you'll meet this on Day 2).
ZeroDivisionErrorYou divided by zero.
